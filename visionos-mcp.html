VisionOS MCP
Danh mục tính năng của phiên bản MCP — nền tảng Computer Vision chạy trên desktop, hỗ trợ CPU & GPU. Người dùng non-tech tự cấu hình pipeline AI bằng cách mô tả bài toán, không cần chọn model. Xây dựng trên Supervision, YOLO-NAS và LocateAnything.

Cấu hình pipeline AI qua 4 bước — không cần chọn model, chỉ mô tả bài toán
Tính năngMô tảGhi chú kỹ thuật
Pipeline Builder (4 bước)Bước 1: Chọn camera. Bước 2: Mô tả bài toán bằng tiếng Việt (ví dụ "đếm khách hàng ra vào", "cảnh báo xâm nhập vùng cấm"). Template Library6 pipeline mẫu có sẵn: đếm khách vào ra, đếm xe bãi đỗ, cảnh báo xâm nhập, kiểm kê kệ hàng, giám sát an toàn vùng nguy hiểm, phát hiện hành vi bất thường. Chọn template → tự động điền các bước, user chỉ cần tùy chỉnh.Template kèm sẵn zone, rule, kênh alert mặc định.

Phát hiện và theo dõi đối tượng bằng AI — realtime và tìm kiếm

Object DetectionPhát hiện 80+ lớp đối tượng COCO bằng YOLO, hoặc mô tả tự do bằng tiếng Việt qua LocateAnything. CPU: YOLOv8n ONNX INT8 (10–30fps). GPU: YOLOv8s TensorRT (60–120fps).CPU: ONNX Runtime. GPU: TensorRT. LocateAnything: GGUF q8 cho CPU.

4. Counting
Đếm đối tượng theo vùng, đường kẻ, nhiều lớp — lưu lịch sử và biểu đồ
Tính năngMô tảGhi chú kỹ thuật
Zone CountĐếm số đối tượng đang có mặt trong vùng polygon tại thời điểm hiện tại. Cập nhật mỗi frame, hiển thị badge trên overlay camera. Hỗ trợ đếm bằng mô tả tự nhiên (LocateAnything).sv.PolygonZone.trigger(detections)
Line CountĐếm số lượt đối tượng vượt qua đường kẻ theo chiều vào/ra. Tránh đếm trùng nhờ ByteTrack. IN / OUT / NET riêng biệt.sv.LineZone.in_count / .out_count
Multi-class CountĐếm riêng từng loại đối tượng trong cùng một vùng: người, xe máy, ô tô, hộp — mỗi loại có bộ đếm và màu riêng.Filter detections theo class_id trước khi zone/line trigger.
Multiple ZonesTạo nhiều vùng độc lập trên cùng một camera, mỗi vùng có tên, màu và ngưỡng cảnh báo riêng. Hỗ trợ cả zone polygon và line zone đồng thời.Mảng List[sv.PolygonZone] + List[sv.LineZone] chạy song song.
Occupancy / Threshold AlertĐặt ngưỡng tối đa cho vùng. Khi vượt: viền zone đổi đỏ, gửi alert + ghi log. Hữu ích kiểm soát sức chứa theo quy định an toàn.Kết hợp Alert Rules: IF count > max THEN alert
Event & Count Storage (SQLite)Snapshot định kỳ ghi số đếm mỗi 1/5/15/60 phút vào SQLite. Lưu lịch sử alert kèm snapshot. Analytics Dashboard đọc dữ liệu từ SQLite để vẽ biểu đồ xu hướng.SQLite local. Snapshot: camera_id, zone_id, count, timestamp. Alert: event log append-only.
5. Alert
Cảnh báo thông minh, giảm false alarm, gửi đa kênh
Tính năngMô tảGhi chú kỹ thuật
Alert Rules (IF/THEN)Tạo rule với điều kiện: IF object trong zone AND thời gian ở lại > N giây OR count > max THEN alert. Đặt lịch active, cooldown per rule. Hỗ trợ AND/OR/NOT.Logic engine đơn giản, kiểm tra mỗi frame.
Smart DebounceChỉ gửi 1 alert mỗi N giây cho cùng một sự kiện. Mặc định 30 giây, user tùy chỉnh. Gom nhóm alert liên quan trong 30s thành 1 incident.
Alert InboxDanh sách alert với vòng đời: Mới (new) → Đã xử lý (closed). ACK (xác nhận) ngay trên Live Dashboard. Close kèm ghi chú. Lưu ai xử lý, lúc mấy giờ, ghi chú gì.Audit trail cho mỗi alert.
Alert SnapshotMỗi cảnh báo kèm ảnh chụp màn hình tại thời điểm phát hiện, có bounding box và metadata (camera, zone, confidence, số đếm).Lưu frame dưới dạng JPEG base64 hoặc file local.
Multi-channel DeliveryGửi alert qua In-app notification + Email (SMTP) + Webhook. Kênh do Admin cấu hình, Operator chỉ chọn từ danh sách có sẵn.SMTP config trong Settings. Webhook: POST JSON đến URL.

VisionOS MCP
VisionOS MCP — Kiến trúc Desktop App
Ứng dụng Computer Vision chạy local, CPU-first, GPU optional, dành cho người dùng non-tech
Tổng quan
Desktop app giám sát nhiều camera AI đồng thời. User thêm camera URL → mô tả bài toán → hệ thống tự động chọn model và chạy. Giao diện đơn giản, không cấu hình kỹ thuật.
Công nghệ nền tảng
Frontend: Tauri v2 + React + Tailwind
Backend: Python sidecar (inference engine)
Detection: YOLOv8n ONNX (CPU) / TensorRT (GPU)
Zero-shot: LocateAnything GGUF q8
Tracking/Counting: Supervision ByteTrack + PolygonZone + LineZone
Search: CLIP ViT-B/32 + FAISS
Phạm vi MCP
7 nhóm tính năng: Quản lý camera · AI Pipeline · Detection · Counting · Alert · Dashboard · Quản trị. Không bao gồm: Video Archive, REST API, Behavior Detection, PPE, OCR.
Yêu cầu phần cứng
CPU mode: Intel i5 / AMD Ryzen 5 (8+ core), 16GB RAM, 10GB disk
GPU mode: NVIDIA GTX 1660+ (6GB VRAM), CUDA 12.x
Hỗ trợ: 2–8 camera @ 5–10fps (CPU) / 15–30fps (GPU)

✓ LRU Inference Cache: Kết quả LocateAnything và YOLO được cache trong session (TTL 5 phút, max 100 entries). Key: (model_name, query_text, frame_hash). Nếu user search "người áo đỏ" nhiều lần, cache trả kết quả ngay lập tức thay vì chạy inference lại. Cache tự động invalidate khi pipeline config thay đổi.
ℹ️ CLIP Indexer chạy process riêng, độc lập với pipeline realtime. Frame được CLIP embed ở tốc độ ~1fps (CPU) / ~5fps (GPU), append vào FAISS index. Không ảnh hưởng đến detection realtime. Khi search, CLIP vector search ~200ms, sau đó LocateAnything rerank on-demand nếu cần.
3
Luồng xử lý Pipeline
Từ người dùng mô tả bài toán đến kết quả realtime
1
User mô tả bài toán (Bước 2 Pipeline Builder)
User nhập: "đếm khách hàng ra vào cửa hàng". Hệ thống phân tích từ khóa → detect "người" (COCO) → chọn YOLO. Hoặc "đếm hộp carton màu vàng" → không có trong COCO → chọn LocateAnything.
2
Camera → Decode Worker (process riêng)
FFmpeg decode stream RTSP thành numpy array. Mỗi camera 1 process riêng. Frame được sample: chỉ lấy 1/N frame để xử lý AI (5fps mặc định). BGR → RGB chuyển đổi ngay sau decode.
3
YOLO / LocateAnything → sv.Detections
YOLO chạy inference → output bounding boxes + class_id + confidence. Supervision chuyển thành sv.Detections. Nếu là LocateAnything, kết quả text → parser → sv.Detections.
4
ByteTrack → Zone/Line → Counting
ByteTrack gán track_id. PolygonZone.trigger() kiểm tra ai trong vùng. LineZone.trigger() đếm IN/OUT. Kết quả đẩy lên IPC để UI cập nhật badge realtime.
5
Alert Engine → Inbox + Delivery
Kiểm tra IF/THEN rules. Smart debounce chặn spam. Nếu trigger: lưu alert vào SQLite + snapshot JPEG + gửi qua các kênh đã cấu hình. UI cập nhật Alert Inbox realtime.
